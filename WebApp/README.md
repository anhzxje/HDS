# HDS WebApp

Giao diện React và Vite cho quản lý sản phẩm và xuất hàng. Xem [README dự án](../README.md) để cấu hình SQL Server, chạy API và tìm hiểu chức năng.

```bash
npm install
npm run dev
```

Mặc định giao diện chạy tại `http://localhost:5173`; Vite chuyển yêu cầu `/api` tới backend tại `http://localhost:5252`. Có thể thay đổi proxy trong `vite.config.js`.

Các lệnh khác: `npm run lint` kiểm tra mã nguồn, `npm run build` tạo bản build và `npm run preview` xem thử bản build.
